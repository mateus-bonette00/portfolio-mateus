Comandos principais

Use estes comandos para instalar o pacote completo ou uma skill específica.

Observação importante: eu não consigo ver diretamente a sua pasta local do Codex. A lista abaixo é baseada no registry oficial do repositório Leonxlnx/taste-skill. Se você instalou pelo pacote completo, estas são as skills que provavelmente vieram dele.
npx skills add Leonxlnx/taste-skill -a codex pacote completo
npx skills add https://github.com/Leonxlnx/taste-skill --skill "gpt-taste" skill específica
find ~/.codex ~/.agents -name "SKILL.md" -print 2>/dev/null listar no Linux

Skills principais de front-end e redesign

Essas são as mais úteis para seu portfólio, landing pages, UI premium e melhorias visuais em código existente.

01
geral

taste-skill

Nome internodesign-taste-frontend
Instalação--skill "taste-skill"
TipoImplementação de front-end

É a skill base do pacote. Serve como padrão seguro para criar interfaces premium sem prender o projeto em um único estilo visual. Trabalha layout, tipografia, movimento, componentes, espaçamento, cores e performance.

Use quando

Você quer melhorar a qualidade geral do front-end sem pedir uma estética muito específica.

02
Codex

gpt-taste

Nome internogpt-taste
Pastagpt-tasteskill
TipoFront-end criativo e rígido

Variante mais forte para GPT e Codex. Força maior variação de layout, direção visual mais ousada, motion com GSAP, estrutura AIDA para landing pages, grid mais bem resolvido e checagens mais agressivas contra visual genérico.

Use quando

Você quer que o Codex pare de criar card comum, hero genérico e layout com cara de template automático.

03
projeto existente

redesign-skill

Nome internoredesign-existing-projects
Instalação--skill "redesign-skill"
TipoAuditoria e redesign

Skill feita para projetos que já existem. Primeiro ela lê a base, identifica framework, CSS, padrões visuais, problemas de tipografia, cor, layout, estados faltantes e só depois aplica melhorias sem reescrever tudo do zero.

Use quando

Você já tem um site pronto e quer corrigir contraste, espaçamento, cards, responsividade e aparência premium sem quebrar funcionalidades.

04
imagem para código

image-to-code-skill

Nome internoimage-to-code
Instalação--skill "image-to-code-skill"
TipoPipeline visual para implementação

Faz o fluxo imagem primeiro. A skill orienta o agente a gerar referências visuais, analisar profundamente essas referências e depois implementar o front-end tentando preservar a intenção visual, o espaçamento, a hierarquia e a composição.

Use quando

Você quer criar uma imagem de referência do layout e depois mandar o Codex transformar aquilo em código fiel.

05
premium suave

soft-skill

Nome internohigh-end-visual-design
Instalação--skill "soft-skill"
TipoUI calma, cara e polida

Direciona o agente para um visual de agência premium, com contraste mais suave, muito espaço em branco, fontes melhores, microinterações fluidas e menos aparência de site barato. É boa para produto SaaS, IA, portfólio elegante e interface moderna.

Use quando

Você quer algo bonito, refinado, calmo e profissional, sem visual pesado ou agressivo.

06
minimalista

minimalist-skill

Nome internominimalist-ui
Instalação--skill "minimalist-skill"
TipoUI editorial limpa

Cria interfaces no estilo produto editorial, com sensação parecida com Notion, Linear e ferramentas limpas. Usa paleta restrita, estrutura clara, hierarquia tipográfica forte, bento grids planos e evita gradientes, neon, sombras pesadas e glassmorphism exagerado.

Use quando

Você quer um site limpo, chique, organizado e fácil de ler, sem excesso visual.

07
beta

brutalist-skill

Nome internoindustrial-brutalist-ui
Instalação--skill "brutalist-skill"
TipoExperimental e brutalista

Cria interfaces brutas, mecânicas e experimentais. Mistura tipografia suíça, estética de terminal, grids rígidos, contraste forte, visual de blueprint, HUD militar, CRT, tabelas e linguagem mais técnica.

Use quando

Você quer um visual muito marcante, técnico, artístico, denso ou diferente do padrão comercial comum.

08
completude

output-skill

Nome internofull-output-enforcement
Instalação--skill "output-skill"
TipoResposta completa

Não é uma skill de design visual. Ela serve para impedir que o agente entregue código pela metade, use comentários como "resto do código aqui", pule partes ou entregue uma estrutura incompleta quando você pediu arquivo completo.

Use quando

Você quer que o Codex entregue arquivos completos, componentes completos e nada de placeholder preguiçoso.

09
Google Stitch

stitch-skill

Nome internostitch-design-taste
Instalação--skill "stitch-skill"
TipoDesign system para Stitch

Cria arquivos DESIGN.md pensados para o Google Stitch. Traduz padrões de UI premium para regras semânticas de design, com cores, tipografia, componentes, layout, movimento e lista de padrões proibidos.

Use quando

Você usa Google Stitch ou quer transformar uma direção visual em um DESIGN.md reaproveitável.

Skills de geração de imagem

Essas skills são para gerar imagens de referência. Elas não são, por si só, skills de implementação de código.

10
web image

imagegen-frontend-web

Nome internoimagegen-frontend-web
Instalação--skill "imagegen-frontend-web"
TipoImagem de seções web

Gera imagens horizontais de seções de site, como hero, landing page, página de produto e multi-section. A regra principal é criar uma imagem separada para cada seção, em vez de juntar a página inteira em um frame gigante.

Use quando

Você quer referências visuais de seções do portfólio antes de mandar o Codex implementar.

11
mobile image

imagegen-frontend-mobile

Nome internoimagegen-frontend-mobile
Instalação--skill "imagegen-frontend-mobile"
TipoImagem de telas mobile

Gera conceitos visuais para apps mobile, fluxos de onboarding, login, dashboards, perfil, configurações, e-commerce, fintech, produtividade e outras telas. Foca em leitura, consistência, safe area e aparência nativa de app.

Use quando

Você quer planejar telas mobile antes de codar ou antes de pedir uma implementação app-like.

12
marca

brandkit

Nome internobrandkit
Instalação--skill "brandkit"
TipoIdentidade visual

Gera boards de identidade visual com logo, paleta, tipografia, aplicações da marca, mockups e linguagem visual. É voltada para criar uma direção de marca com aparência de estúdio profissional.

Use quando

Você quer criar uma identidade visual para seu portfólio, empresa, produto, SaaS ou projeto antes de codar o site.

Qual usar em cada situação

Tabela prática para decidir rápido qual skill chamar no Codex.

Situação Skill recomendada Motivo Prioridade para seu portfólio
Melhorar seu site atual sem quebrar nada redesign-skill Audita a base existente e aplica melhorias direcionadas. Alta
Criar visual moderno e menos genérico no Codex gpt-taste É mais rígida para GPT/Codex, com mais variação de layout e motion. Alta
Criar uma nova seção premium do zero taste-skill É o padrão geral mais seguro para UI premium. Alta
Transformar uma imagem de referência em código image-to-code-skill Força o fluxo imagem, análise e implementação fiel. Alta
Gerar referência visual de seções antes de codar imagegen-frontend-web Cria imagens horizontais por seção para handoff ao Codex. Alta
Fazer um design limpo, editorial, organizado minimalist-skill Evita excesso visual e cria hierarquia limpa. Média
Fazer um visual de agência premium, suave e caro soft-skill Melhora sensação visual com espaço, contraste suave e microinterações. Média
Impedir código incompleto ou com placeholder output-skill Obriga o agente a entregar tudo completo. Alta
Criar identidade visual antes do site brandkit Gera board de marca, paleta, tipografia e aplicações. Média
Criar app mobile ou telas mobile imagegen-frontend-mobile Cria mockups mobile e fluxos com aparência app-native. Baixa
Criar algo experimental, técnico e brutalista brutalist-skill Visual mais agressivo, denso e fora do padrão comercial. Cuidado
Usar Google Stitch com design system stitch-skill Gera DESIGN.md para o Stitch seguir uma direção premium. Baixa

Combinação recomendada para o seu portfólio

Se eu fosse usar no seu caso, eu chamaria as skills nesta ordem.

Ordem Skill Pedido ideal para o Codex
1 redesign-skill Analise meu portfólio atual, identifique problemas visuais e melhore sem reescrever tudo.
2 gpt-taste Aplique uma direção mais premium, moderna, criativa e menos genérica.
3 output-skill Entregue os arquivos completos, sem placeholder, sem trechos faltando.
4 imagegen-frontend-web Quando quiser pensar uma seção nova visualmente antes de codar.
5 image-to-code-skill Quando você já tiver uma imagem de referência e quiser transformar em código.
